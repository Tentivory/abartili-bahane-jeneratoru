# 🎭 Abartılı Bahane Jeneratörü

**Dünyanın en ciddiye alınan en saçma projesi.**

Bu repository, modern insanın en büyük ihtiyacını karşılamak üzere tasarlanmıştır: **İş yapmamak için bilimsel, felsefi ve duygusal olarak geçerli bahaneler üretmek.**

## Neden Bu Proje Var?

Çünkü:
- Çay demlenirken düşünmek bir haktır.
- Klavye de yorulur.
- GitHub Copilot bazen "sen dinlen" der.
- Ve en önemlisi: **Yok artık.**

## Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/abartili-bahane-jeneratoru.git
cd abartili-bahane-jeneratoru
python bahane_uretec.py
```

Program çalıştığında biraz bekler (çünkü acele işe şeytan karışır), sonra size günün en abartılı, en inandırıcı ve en gereksiz bahanesini sunar.

## Özellikler

- %100 gerçek Python kodu (inanmıyorsanız bakın)
- Rastgele seçim algoritması (yani random.choice)
- Bilimsel gecikme (time.sleep ile kanıtlanmış tembellik)
- Türkçe dil desteği (ve biraz da ruh hali desteği)
- Hiçbir şey yapmaz ama her şeyi yapmış gibi hissettirir

## Lisans

Bu proje "Yok Artık Lisansı" altındadır. İstediğiniz gibi kullanın, ama kullanırken bahane üretmeyi unutmayın.

## Katkıda Bulunma

Yeni bahane önerileriniz varsa PR açın. Ama açmadan önce bir bahane üretin, belki gerek kalmaz.
